# Codex

Either install the plugin (this repository is a plugin marketplace):

```bash
codex plugin marketplace add nextbillion-ai/nextbillion-mcp
codex plugin add nextbillion-mcp@nextbillion
```

or add the hosted server directly:

```bash
codex mcp add nextbillion --url https://mcp.nextbillion.io
```

Codex detects the OAuth sign-in and opens the browser; paste your NextBillion.ai API key once.
The plugin carries no code — only the server URL.
